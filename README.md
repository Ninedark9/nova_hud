# NOVA HUD

Lightweight and modern FiveM HUD with support for **NOVA Framework**, **QBCore**, **ESX Legacy**, and standalone servers.

## Features

- Health and armour
- Hunger and thirst
- Circular minimap
- Compass and street information
- Vehicle speed
- RPM and gear display
- Fuel and engine status
- Seatbelt system
- Automatic framework detection
- QBCore, ESX Legacy support
- Standalone support

You only need **one** of the following:

- [QBCore](https://github.com/qbcore-framework/qb-core)
- [ESX Legacy](https://github.com/esx-framework/esx_core)
- NOVA Framework
- Standalone mode
- OneSync recommended
